# Marketur App Kit

Turns a website into a real iPhone and Android app with a native tab bar, onboarding,
push notifications, quick actions and an offline screen, then fills in the App Store and
Google Play pages for it. One repository, one folder per customer.

    node scripts/apply-customer.mjs customers/<slug>

See RUNBOOK.md for the whole flow and customers/example/customer.json for every setting.
